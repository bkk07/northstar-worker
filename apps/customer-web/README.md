# customer-web (Phase 1)

Separate customer storefront (spec §4). Professional shell + routes only;
auth/products/cart/orders/tickets arrive in Phases 2–5.

- Dev: `npm install && npm run dev` → http://localhost:5174
- API: `VITE_API_URL` (default http://localhost:8000)
- Routes: `/ /login /signup /products /products/:id /cart /orders /orders/:id /support /tickets/:id`
